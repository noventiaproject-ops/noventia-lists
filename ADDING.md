# Adding or correcting an entry

An entry enters a list when all of this holds:

1. **It is a service.** An exchange, a launchpad, a locker, a bridge or a program that serves many unrelated people. An address of a person is not accepted in any list.
2. **It has a public source.** The project's own documentation, repository or package, at a pinned commit where there is one, or a derivation anyone can repeat, such as a program address derived from published seeds. For a DEX that publishes no address of its own, Jupiter's official map from program to DEX name is accepted, and the entry says so. A personal account of a developer is not a source.
3. **It can be checked on chain.** A program is read on chain and is executable. A derived address matches the derivation.

To propose an entry or a correction, open an issue with the address, the name, the kind of service and the link to the source. A change is made in the core first, with a new version of the list, and then appears here.

An address that is absent from the lists is not recognized, and nothing is concluded from that.
